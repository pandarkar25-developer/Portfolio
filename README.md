# Personal Portfolio

A responsive static portfolio website ready for GitHub Pages.

## Customize

Open `index.html` and replace:

- `Your Name`
- `your.email@example.com`
- `YOUR_USERNAME`
- Project descriptions and GitHub links
- LinkedIn username

## Run locally

Double-click `index.html` or open it in a browser.

## Upload to GitHub

```bash
git init
git add .
git commit -m "Add portfolio"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/portfolio.git
git push -u origin main
```

Then enable GitHub Pages from repository Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

## Structure

- `index.html` — portfolio content
- `style.css` — responsive styling
